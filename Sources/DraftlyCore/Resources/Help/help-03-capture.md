# Capture and multiple windows

Choose File → Capture to open a separate window for quick text. The menu bar icon also opens Capture. The default global shortcut is ⌃⌥⌘N; review your configured shortcuts if it does not work.

Capture can save text as a new draft or append it to an existing draft. Pending Capture text stays on this Mac when you close the window or restart the app.

## Use more than one editor
Choose File → New Draft in New Window. Each window has its own editor and selection. Check which window is active before you run an action or ask a model to edit the current draft.

Pin Current Draft keeps the current draft when you return to the app. Settings → General controls New Draft After, which starts a new draft after an idle period. Its default is five minutes.

## Launch behavior
Settings → General includes launch preferences. Launch at Login uses the macOS login-item service. If macOS requires approval, review System Settings → General → Login Items & Extensions. A saved preference alone does not prove that macOS accepted the login item.
