# Start here

Draftly is a writing space for Mac. A draft is one text item in your library. A workspace is a saved view of that library. An action performs a sequence of steps on text.

## Your first draft
1. Choose File → New Draft, or press ⌘N.
2. Write a title on the first line, then write your text.
3. Pause briefly to let Draftly save. Content also saves before you move to another draft.
4. Select the draft in the list to return to it.

An empty new draft stays temporary until you type, add metadata, or run an action. There is no need to create a file for each draft.

## Find your way around
The window can show filters, the draft list, the editor, Actions, and Chat Console. The View menu and toolbar show or hide these panels. Drag panel dividers to change their widths.

The editor is for your draft. The chat input is for a message to a model. They have separate text, selection, and Undo history.

Draftly requires macOS 26 or later. There is one edition, with no Pro tier. This guide is included in the app and works offline. Links to websites need an internet connection.
