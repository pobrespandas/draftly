# Tags, flags, Archive, and Trash

Use Inbox for active drafts. Archive keeps a draft in the library but removes it from Inbox. Trash holds drafts until you empty it.

## Add and change tags
Enter tags separated by commas in Add tag…, then press Return. Right-click a sidebar tag to rename or remove it. Removing a tag keeps its drafts and updates saved workspace filters.

Use the flag control to mark a draft. A flag and a tag are separate ways to organize text.

## Row and batch actions
Swipe a list row to reveal its actions. Archive and Trash act on that row. Archived rows offer Inbox; trashed rows offer Restore. Use Command-click or Shift-click to select several drafts for batch commands. Check the selection before using a batch command.

## Recover a trashed draft
Select Trash in the draft list, select the draft, then use Restore. Empty Trash permanently removes trashed drafts after confirmation. Do not empty Trash to solve a search or display problem.

An archived draft is not a backup. A trashed draft is not a saved version. Use a full backup for recovery outside the current library.
