# iCloud and local storage

Settings → iCloud shows the current library synchronization status. In a build configured for iCloud, Check iCloud Account refreshes the account check. A local development build can have no iCloud container.

## Understand the status
A successful local save means this Mac stored the change. It does not confirm that another Mac received it. An account check is also not proof that every record finished synchronizing.

If a change is missing on another Mac, check the account, connectivity, app version, sync status, and active filters on both Macs. Keep both copies until you understand the difference. Export backups before attempting recovery.

Drafts and library data can synchronize. Folder permissions and other Mac-specific access still need review on each Mac. Do not edit the library's internal files while Draftly is running.

Show Library Folder opens the app's local storage location. Copying one internal file is not a substitute for Export Full Backup.

## Offline work
You can write locally while offline. Reconnection and conflict handling are separate from the act of saving. Review concurrent edits rather than assuming the newest visible text is the only copy.

This version does not provide a verified reset or delete-all-cloud-data workflow. Do not remove cloud or local files as a first troubleshooting step.
