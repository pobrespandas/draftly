# Run and manage actions

Actions perform ordered steps on text. Use the Actions panel, the command palette, or an assigned keyboard shortcut to run one. The default command-palette shortcut is ⇧⌘P.

The included catalog has five groups: Basic, Editing, Markdown, Tools, and Processing. Group tabs and the group menu change the visible group. Search Actions searches across groups.

## Before running an action
Check the active draft, selected text, action configuration, and any confirmation. Some actions use other apps, files, accounts, or macOS permissions. A visible action is not proof that every dependency is available.

## Inspect a result
Open Actions → Execution History… to inspect a run or an error. Use Actions → Cancel Running Action when a run must stop. Cancellation cannot recall an effect that another app or service has already completed.

## Import or edit
Actions → Import from Directory… imports an action. Review imported scripts before running them. Actions → Manage Actions and Workspaces… controls groups and ordering. The action editor controls steps, configuration, keyboard shortcuts, and changes to tags or flags after success.

Unknown steps stay stored. An enabled unsupported step can prevent a run. Disabled unsupported steps are kept but do not run. Drafts compatibility is still in development.

During catalog stabilization, updates replace all actions and groups. Keep an exported backup if you need to retain custom actions.
