# Install and update

Download Draftly from [the official site](https://draftly.pobrespandas.com/). Open the DMG and drag Draftly to Applications. Open the copy in Applications, then eject the disk image.

## Check for an update
Choose Draftly → Check for Updates…. The public app checks the signed stable update feed and asks before installing an update. A development build can have updates disabled. Download the public app if that command is missing in a local build.

Public release packages are signed and notarized. Alpha and beta releases are marked separately on GitHub. The main website offers the stable release.

## Current action replacement policy
During catalog stabilization, installation and updates restore the complete default action catalog once per installation. This replaces custom and modified actions and groups, and restores deleted defaults. Drafts are preserved. Export a full backup before updating if you need to retain your action configuration.

An existing iCloud catalog waits for a successful import before replacement. An empty cloud library receives defaults immediately. Reopening the same installation does not repeat the replacement.

Updating the app is separate from iCloud synchronization. A successful update does not establish that another Mac has received your drafts.
