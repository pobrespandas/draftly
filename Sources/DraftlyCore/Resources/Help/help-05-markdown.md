# Markdown and preview

Choose Markdown as the editor syntax to highlight Markdown while you write. Syntax highlighting does not convert the draft into a rich-text document.

## Common formatting
- Use `# Heading` for a heading.
- Use `**bold**` and `*italic*` for emphasis.
- Start a line with `- ` for a list.
- Use `- [ ] Task` for a task checkbox in Markdown.
- Use `[title](https://example.com)` for a link.
- Start a line with `> ` for a quote.
- Put code between lines that contain three backticks.

## See the rendered document
Choose View → Markdown Preview, click the eye button below the editor, or use the default shortcut ⌥⌘P. Return to editing to change the source.

Chat responses also render Markdown. Copy on a chat response copies the original text, including Markdown markers. It does not copy a rendered web page.

Imported action previews can use different engines or templates. Not every Drafts preview or scripting contract is identical in Draftly. Check the result with your own content before using an imported workflow.
