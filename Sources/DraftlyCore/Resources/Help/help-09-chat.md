# ChatGPT and Apple Intelligence

Open Chat Console with the chat toolbar control or the View menu. Choose a model from its header. Use the account control to sign in to ChatGPT. Complete the official sign-in in the browser; do not put credentials in a chat message.

Apple Intelligence On-Device requires a compatible Mac with Apple Intelligence enabled and its local model available. ChatGPT sends requests to the selected provider account. Apple On-Device runs on the Mac. Apple Cloud is not a verified general Private Cloud Compute connection in Draftly; do not assume it is available.

## Write and send
Return sends a message. Shift-Return adds a line. During input-method composition, Return confirms the marked text first. The input grows to five lines, then scrolls internally. Stop cancels a response in progress.

The chat follows new responses while you stay near the bottom. Scroll up to read older messages. Latest message returns to the bottom. Starting another conversation keeps conversations separate.

## Use a response
Create draft makes a new draft from a response. Insert adds it to the current draft. Copy copies the original Markdown. These controls are different from a model tool call. Review the destination before inserting text.

## Check what really changed
A model should claim a saved change only after a tool confirms it. Proposed text in a response is not proof of a saved draft. Ask the model to read back the created draft or edited editor, then inspect it.

Apple Intelligence can misunderstand a request or fail to use a tool, including Undo. If Draftly reports an unverified result, inspect the draft before trying again. Repeated read verification can stop with a factual receipt. That receipt does not mean all requested work finished.
