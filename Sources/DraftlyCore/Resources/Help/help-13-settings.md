# Fonts, themes, syntax, and shortcuts

Choose Draftly → Settings… for general preferences, iCloud status, Agents, and Maintenance. Choose Editor Settings… for writing preferences. The default settings shortcut is ⌘,; Editor Settings uses ⌥⌘,.

Editor settings include fonts, size, spacing, margins, maximum width, themes, and syntax-specific options. A per-syntax override can differ from the general font. Use the relevant Reset control to remove that override.

Markdown syntax controls source highlighting. The preview controls rendered presentation. Chat input shares editor presentation while keeping its own session and Undo history.

## Keyboard shortcuts
Settings → Shortcuts shows command assignments. Menu items show the active shortcut. Imported actions can have shortcuts too. Review a conflict before assigning the same shortcut twice.

Default examples:
- ⌘N: new draft.
- ⌃⌥⌘N: global Capture.
- ⇧⌘P: command palette.
- ⌥⌘P: Markdown preview.
- ⌘Z: Undo in the focused editor.
- ⇧⌘Z: Redo.
- ⌘?: Draftly Help.

The configured shortcut and current focus determine the result. The draft and chat editors do not share Undo history.
