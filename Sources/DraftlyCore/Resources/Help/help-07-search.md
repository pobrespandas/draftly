# Search and workspaces

Find in Draft List searches the list. Quick Search opens a separate search window. Find in the editor searches only its current text.

## Use Quick Search
Open Quick Search from the View menu or toolbar. Type a search, use Up and Down to choose a result, then press Return to open it. Escape closes the search.

If a draft seems missing, clear search text and tag filters. Check Archive and Trash. Confirm that the selected workspace includes the draft.

## Save a workspace
A workspace stores a view of the library, including search, tags, and sort order. It does not make a second copy of the drafts. Manage workspaces from Actions → Manage Actions and Workspaces….

List Options controls preview lines, tags, and dates in the list. These display settings stay on this Mac. Changing a preview does not change the draft.

For a large library, use search and filters before selecting items. Agent access can cover the whole library without selecting every draft individually.
