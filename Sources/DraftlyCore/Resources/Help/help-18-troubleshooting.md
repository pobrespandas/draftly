# Troubleshooting and support

## I cannot find a draft
Clear the search, workspace, and tag filters. Check Archive and Trash. Confirm that you are in the expected library and Mac. Inspect iCloud status if you use synchronization. Do not empty Trash or delete local files.

## Actions are missing or have old icons
Clear Search Actions and check the selected group. Check the installed app version. Read the catalog replacement policy before using Settings → Maintenance → Replace Default Actions…. Export a backup first if action changes matter to you.

## The model says it cannot create or edit
Open the chat tools status. Check local access, sign-in, model availability, expiry, and connection scope. Creation needs creation capability and library access; editing an existing draft is not the same permission. Start a new request after resolving the status.

## The model says it changed text, but the editor differs
Inspect the actual draft and editor. Ask for a read of the same resource. Do not repeat an uncertain effect automatically. Apple can fail to use Undo; use the editor's Undo only after checking the current text and focus.

## Apple Intelligence is unavailable
Check that the Mac supports Apple Intelligence and that it is enabled in macOS. The local model must be ready. A ChatGPT sign-in does not enable Apple's local model. Private Cloud Compute is not a verified alternative in this release.

## An update does not appear
Check Draftly → Check for Updates…. Confirm that you opened the copy in Applications. Development builds can disable updates. Use the official stable download if needed, and export a backup before replacing an installation.

## A native action fails
Read Execution History. Check the target app, folder, and macOS permissions. For an uncertain external result, inspect the destination before retrying.

## Report a problem
Use [GitHub Issues](https://github.com/pobrespandas/draftly/issues). Include the Draftly version and build from About, macOS version, steps, expected result, actual result, and any visible error. Use neutral sample text. Remove draft content, account details, tokens, and connection commands from screenshots and logs.
