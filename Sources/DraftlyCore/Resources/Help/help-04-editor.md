# Write, select, and undo

Type or paste text in the main editor. Use standard Mac selection, Cut, Copy, Paste, Undo, and Redo commands. The bottom action bar includes editing actions such as task formatting, dates, indentation, and line movement.

## Undo and saved versions
Undo changes the recent editing history in the current editor. Redo reapplies an undone edit. Save Version creates a saved version of a draft. Versions and Revision History let you inspect earlier saved content. They are not the same as the current editor Undo history.

Before restoring content, check the draft and version you selected. Export a backup before a broad recovery operation.

## Search inside text
Choose Edit → Find…. This searches the editor, not the library. General settings can select the advanced find panel. Use Quick Search or Find in Draft List to locate other drafts.

## Unsaved editor content
An agent can be authorized to read the open editor, including text that has not yet been saved. A saved draft read and an editor read can therefore return different text. When checking an edit, read the same resource that was edited.
