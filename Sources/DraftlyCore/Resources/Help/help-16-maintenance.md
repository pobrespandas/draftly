# Maintenance and default actions

Settings → Maintenance includes Replace Default Actions…. Read the confirmation before applying it.

This command replaces the current default Basic, Editing, Markdown, Processing, and Tools actions, including their symbols and colors. It overwrites edited defaults and restores deleted defaults. Other actions remain.

## Maintenance command versus update
Replace Default Actions is an explicit repair command. The temporary installation/update policy is broader: an app installation or update restores the complete catalog and replaces all actions and groups, including custom ones, once per installation. Drafts remain.

Export a full backup before changing an action catalog you need to keep. After replacement, check the selected group and clear the action search if expected actions are not visible.

Library Summary shows counts for drafts and related library content. It is a diagnostic view, not a repair or synchronization command.

Do not delete library files or revoke unrelated folder permissions to refresh an icon. If replacement fails, retain the error and report it with the app version.
