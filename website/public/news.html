November 10, 2026Draftly 0.5.0

A chat that fits your writing space

Chat Console renders Markdown and shares the native editor presentation. Its composer grows to five lines with separate Undo and selection. New replies follow the bottom; Latest message brings you back after reading older text.

With local access on, tools connect automatically when the provider is available. New libraries enable local agent access. This update expands active, unexpired connections to the entire library and available tools once. Saved access off, Stop Work, expiry dates, and revoked connections remain effective.

ChatGPT and Apple Intelligence confirm changes from current tool results. Apple can still misunderstand a request; review the edited text. Destructive and external effects still require review. The temporary default-action replacement policy continues and preserves drafts.

November 7, 2026Draftly 0.4.0

The complete local tool catalog

The local MCP catalog has 137 operations for drafts, editors, actions, imports, backups, and native integrations. Clients see tools allowed by the current connection. Native operations retain system permissions and review.

This release kept local agent access off by default. Version 0.5.0 changes the defaults for new libraries and expands active connections once.

November 3, 2026Draftly 0.1.10

Default actions without the wait

A fresh iCloud library now gets all five default action groups immediately, with their symbols and colors. An unavailable or delayed import no longer leaves the action panel empty.

When import succeeds, Draftly completes the pending catalog replacement without duplicate defaults. The temporary update policy still replaces custom and edited actions; drafts are preserved. Agent access remains disabled.

November 3, 2026Development update

Clearer versions and release notes

Draftly now has a release process for stable, alpha, and beta versions, with a changelog. Alpha and beta builds will be marked as test releases. Each download must pass its tests, signing, and notarization checks before publication.

This release process is in place. Local agents and Chat Console are still in development and are not included in that release.

Smoother text composition

This update preserves marked text while the editor updates and reduces repeated syntax analysis.

Until the default catalog is stable, each installation or update replaces all Actions and action groups, including custom and edited ones. Your drafts are preserved. Libraries that use iCloud wait for a successful import before the catalog is replaced.

November 2, 2026Draftly 0.1.7

The default Actions return on update

Installing or updating Draftly now restores all five default action groups with their current icons and colors. This temporary policy replaces custom and edited Actions too. Changes made after installation stay until the next installation or update.

Your drafts are preserved. If iCloud is unavailable, the existing catalog stays until an import succeeds.
