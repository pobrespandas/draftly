# Theme sources

Draftly provides independent adaptations of public color palettes. The files use the Drafts theme format because Draftly can import that format. They do not copy the community ports from the Drafts Directory.

- Rosé Pine, Rosé Pine Moon, and Rosé Pine Dawn use the [Rosé Pine](https://github.com/rose-pine/rose-pine-theme) palette. Rosé Pine is available under the MIT License.
- Nord uses the [Nord](https://github.com/nordtheme/nord) palette. Nord is available under the MIT License.
- Flexoki Dark and Flexoki Light use the [Flexoki](https://github.com/kepano/flexoki) palette. Flexoki is available under the MIT License.
- Solarized Dark and Solarized Light use the [Solarized](https://github.com/altercation/solarized) palette. Solarized is available under the MIT License.
- Dracula uses the [Dracula](https://github.com/dracula/dracula-theme) palette. Dracula is available under the MIT License.
- Gruvbox Dark and Gruvbox Light use the [Gruvbox](https://github.com/morhetz/gruvbox) palette. Gruvbox is available under the MIT/X11 License.
- Catppuccin Latte and Catppuccin Mocha use the [Catppuccin](https://github.com/catppuccin/catppuccin) palette. Catppuccin is available under the MIT License.
- Tokyo Night uses the [Tokyo Night](https://github.com/tokyo-night/tokyo-night-vscode-theme) palette. Tokyo Night is available under the MIT License.

The theme names and project names belong to their respective owners. Draftly is not affiliated with these projects.
