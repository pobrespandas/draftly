Dated audits and validation entries are evidence for the versions they tested.
They are not the current task list. Frozen reference snapshots remain under
`research`. Older status snapshots remain under `archive`. Keep useful records
and links when consolidating the maintained guidance.

The local handoff, raw logs, captures, packages, and operation journals are
ignored. Credentials and personal libraries remain outside tracked files.
