# Logos

The logo files are in `Resources/`. This folder does not copy them.

- `Resources/Draftly.icns`: the app icon. It shows two white stacked pages on a blue-to-purple squircle (`icon-gradient-start` to `icon-gradient-end`). Use it where the app is named as a product: About, docs, release notes. Do not recolor or crop it.
- `Resources/DraftlyMenuMark.pdf`: the menu bar template mark, 18 x 18pt, single ink. Its ink is black; macOS tints it as a template image. In other contexts, set it on `canvas` in light appearance only.
